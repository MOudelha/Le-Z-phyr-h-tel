# Le Zéphyr — site vitrine

Site statique créé pour le projet Cesim de l'hôtel fictif « Le Zéphyr ».

## Données Cesim utilisées
Les chiffres affichés dans le site correspondent uniquement à la colonne **Le Zéphyr** du fichier `results-r05.xls` fourni :
- Domestique : 50 chambres
- International : 10 chambres
- Tarif moyen domestique : 97,31 €
- Tarif moyen international : 95,96 €
- Réservation le jour même : 87,50 € domestique / 135,00 € international
- Taux d'occupation : 60,50 % domestique / 80,55 % international

Aucune donnée tarifaire des concurrents n'a été utilisée dans les textes du site.

## Lancer le site
Ouvrir `index.html` dans un navigateur.

Le site utilise des photos distantes d'Unsplash et les polices Google Fonts : une connexion Internet est donc recommandée pour la présentation.

## Personnalisation
- `assets/logo.png` : logo fourni.
- `style.css` : design, couleurs, images et responsive.
- `script.js` : bouton FR/EN et interaction du menu mobile.
- `index.html` : contenu et coordonnées.

Les champs de réservation sont une démonstration front-end : aucun paiement ni système de réservation réel n'est connecté.
